# 懂世界 Math

我先后加入了两层数学数据：Math23K 用来补充基础中文数学单选题，Math Plus 在相同训练预算下继续扩展题型和解题结构。两层数据都采用空 `<think>` 加单字母答案的形式。

| 数据 | 规模 | 原始大小 | gzip | 作用 |
| --- | ---: | ---: | ---: | --- |
| Math23K | 21,799 | 8.4 MB | 1.4 MB | 第一层基础数学题 |
| Math Plus | 21,799 | 8.4 MB | 1.5 MB | 第二层题型与解题结构扩展 |

对应的线上配方中，“懂世界”从 LoRA Seed SFT 的 `0.1357` 提升至 Math23K 阶段的 `0.1487`，加入 Math Plus 后进一步达到 `0.1610`。这两层数据均被保留为有效的提分方向；其中 Math Plus 所在阶段还同时包含其他改动，因此 `0.1487 → 0.1610` 不能全部解释为 Math Plus 的单变量增益。

## Math23K

Math23K 来自 `Azure99/math23k-reborn`。我将中文基础数学题整理为四选一数据，并把监督目标统一为：

```text
<think>
</think>
C
```

最终文件包含 `21,799` 条数据，没有重复 prompt。它是第一层直接进入训练的数学数据，对应“懂世界”从 `0.1357` 提升至 `0.1487` 的阶段。

## Math Plus

Math Plus 是项目中的通俗名称，内部资产版本为 `math_diversity_delta_matched_v1`。它不是简单增加更难的题，而是在小学、初中难度范围内增加应用题、比例、速度、工程、代数、几何、数论和表格题等结构。

| 来源 | 条数 | 主要补充 |
| --- | ---: | --- |
| APE210K | 6,540 | 中文多步应用题、比例、速度、工程与几何 |
| GSM8K-zh | 3,924 | 小学数学应用题与多步组合 |
| Orca Math | 3,706 | 多样化合成应用题 |
| DeepMind Mathematics | 4,360 | 代数、数论、测量、比较与算术 |
| 本地生成表格题 | 2,180 | 查表、统计、比例与加权总价 |
| MathQA | 771 | 带选项的多步数学题 |
| 本地程序验证 puzzle | 318 | 可由程序验证答案的模板题 |
| **合计** | **21,799** | — |

为了避免“数据更多”与“训练预算更大”混在一起，我将 Math Plus 与 Math23K 对齐：

| 检查项 | Math23K | Math Plus |
| --- | ---: | ---: |
| 行数 | 21,799 | 21,799 |
| 监督 label tokens | 152,593 | 152,593 |
| 输入 tokens | 2,560,470 | 2,544,422 |
| 32K packed microbatches | 80 | 80 |
| A / B / C / D | 5,521 / 5,528 / 5,298 / 5,452 | 完全一致 |
| 与 Math23K 精确重叠 | — | 0 |
| 数据内部精确重复组 | — | 0 |

因此，Math Plus 主要改变的是数学题型覆盖，而不是行数、答案位置或监督 token 预算。
