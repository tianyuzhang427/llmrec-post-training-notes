# Half Video

在不改写保留样本的前提下，将懂推荐中的视频目标样本减半，电商、广告和直播保持不变。

| 目标域 | 减半前 | 减半后 |
| --- | ---: | ---: |
| 视频 | 14,868 | 7,434 |
| 电商 | 1,489 | 1,489 |
| 广告 | 1,576 | 1,576 |
| 直播 | 1,271 | 1,271 |
| 合计 | 19,204 | 11,770 |

50% 版本进入了后期高分配方；继续降到 35% 后覆盖和线上效果变弱。由于缺少单变量线上对照，不能独立声称 Half Video 带来提分。

## 合成样例

```json
{
  "system": "[合成推荐任务指令]",
  "prompt": "【用户历史】[合成的跨域交互序列]\n【目标域】短视频",
  "response": "<|video_begin|><s_a_1><s_b_2><s_c_3>"
}
```
